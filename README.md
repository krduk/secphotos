# SecPhotos - iPhone Camera to Google Drive Direct Uploader

SecPhotosは、iPhoneのカメラ機能を使って写真や動画を撮影し、端末の**カメラロール（写真ライブラリ）に保存することなく**、Google Driveの特定フォルダに直接アップロードするセキュアなWebアプリケーションです。

## 特徴
1. **カメラロールのバイパス**: iOS Safariの標準カメラキャプチャ機能を利用するため、撮影されたメディアは端末のストレージ（Photos App）に保存されず、ブラウザのメモリから直接送信されます。
2. **Google Drive APIとの直接通信**: OAuth2認証（Google Identity Services）を利用し、サーバーを介さずにクライアント（ブラウザ）からGoogle Driveへ直接アップロードするため、プライバシーとセキュリティが確保されます。
3. **レジューム可能アップロード**: 大容量の動画ファイルは自動的に分割アップロードされ、進捗状況をプログレスバーで視覚的に確認できます。
4. **PWA対応**: iPhoneのホーム画面に追加することで、アドレスバーなしのネイティブアプリのようなフルスクリーン表示で利用できます。
5. **ローカル一時保存（パケット通信節約）**: ブラウザ内のセキュアな保存領域（IndexedDB）を利用したオフライン/一時保存機能を搭載。モバイル回線時に撮影したファイルを端末内に留め、Wi-Fi環境に入った際にボタン1つで一括アップロードできます。

## クイックスタート

### 1. 開発サーバーの起動
SSL (HTTPS) を有効にしてサーバーを起動します。iOS Safariでカメラ機能を利用し、Googleログインを行うためにはHTTPS接続が必須です。

```bash
python3 server.py --ssl
```

起動すると、以下のようなログが出力されます：

```text
🔒 HTTPS (SSL) SERVER RUNNING
==================================================
Local access:   https://localhost:8000
Network access: https://192.168.1.100:8000
==================================================
```

### 2. iPhoneでのアクセス
1. iPhoneをパソコンと同じWi-Fiネットワークに接続します。
2. サーバー起動時に出力された `Network access` のURL（例: `https://192.168.1.xx:8000`）をiPhoneのSafariで開きます。
3. 自署署名（自己証明書）による警告画面が表示されますが、**「詳細」をタップし、「ページを表示」または「Webサイトを閲覧」**を選択して進めてください。
4. （推奨）Safariの共有メニューから**「ホーム画面に追加」**を選択すると、ネイティブアプリのようにフルスクリーンで使えます。

## Google Cloud Consoleの設定手順

本アプリは完全なクライアントサイドアプリであるため、ご利用にはご自身のGoogle APIの「OAuthクライアントID」が必要です。

### ① プロジェクトの作成
1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスします。
2. 上部メニューから「プロジェクトの選択」をクリックし、「新しいプロジェクト」を作成します。

### ② OAuth同意画面の設定
1. 左メニューの「APIとサービス」 > 「OAuth同意画面」を開きます。
2. ユーザータイプで **外部 (External)** または **内部 (Internal)** を選択して「作成」をクリックします。
3. アプリケーション情報（アプリ名、サポートメールなど）を入力します。
4. 「保存して次へ」を進み、**スコープの追加または削除**をクリックします。
5. 以下の2つのスコープを選択・追加します：
   - `.../auth/drive.file` （本アプリが作成したファイル・フォルダのみの管理権限）
   - `.../auth/userinfo.email` （ログインしたアカウントのメールアドレス表示用）
6. 保存して同意画面の設定を完了します。※ユーザータイプが「外部」の場合は、テストユーザーに自身のGoogleアカウントのメールアドレスを追加してください。

### ③ 認証情報（クライアントID）の作成
1. 左メニューの「APIとサービス」 > 「認証情報」を開きます。
2. 上部の「認証情報を作成」から **OAuth クライアント ID** を選択します。
3. アプリケーションの種類として **ウェブ アプリケーション** を選択します。
4. **承認された JavaScript 生成元** に、アプリのURLを追加します。
   - `https://localhost:8000`
   - `https://[あなたのパソコンのローカルIP]:8000` （例: `https://192.168.1.100:8000`）
5. 「作成」をクリックすると、クライアントID（例: `xxxxxxxxxx.apps.googleusercontent.com`）が発行されます。

## 使い方

1. アプリをiPhoneで起動すると、最初の画面で「クライアントID」の入力を求められます。上記で取得したクライアントIDを入力し、「クライアントIDを保存」をタップします。
2. 次に「Google Driveに接続」ボタンが表示されるので、タップしてGoogleアカウントでサインインし、アクセス許可を与えます。
3. 接続に成功すると、撮影画面に切り替わります。
   - **写真を撮影**: カメラが起動し、写真を撮影して「写真を使用」をタップすると処理が始まります。
   - **動画を撮影**: カメラがビデオモードで起動し、撮影終了後に「ビデオを使用」をタップすると処理が始まります。

### 💾 2つの送信モード
アプリ右上のギアアイコン（設定）から動作モードを切り替えられます。

* **即時アップロードモード（標準）**:
  撮影後、即座にGoogle Driveへアップロードを行います。アップロード完了後、データは端末内から自動的に削除されます。
  
* **ローカル一時保存モード（通信量節約）**:
  撮影したデータはブラウザ内のセキュアな一時保存領域（IndexedDB）に「一時保存済み」カードとしてプールされます。
  モバイル回線時に撮影したファイルをプールしておき、Wi-Fiに接続した状態で画面上部の **「一括送信」** ボタンをタップすることで、一気にアップロードできます。アップロードが成功したファイルは自動的にプールから削除されます。

4. アップロードされたファイルは、Google Driveに自動生成される `SecPhotos` フォルダ（設定で変更可能）の中に、撮影日時付きのファイル名（例: `photo_20260611_232510.jpg`）で保存されます。
5. 撮影された写真・動画は、iPhone内の「写真」アプリ（カメラロール）には一切残りません。

* `style.css` - グラスモルフィズム風のモダンなモバイルUIデザイン（CSS）
* `app.js` - Google認証、フォルダ検索・作成、IndexedDB一時保存、マルチパート／レジューム可能アップロード処理（JS）
* `server.py` - 自己署名証明書の自動生成とHTTPSサーバー（Python）
* `README.md` - 本ドキュメント
