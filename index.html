SecPhotos

初期設定

Google Driveに直接写真を保存するため、Google Cloud Consoleで作成した「クライアントID」が必要です。

クライアントIDの取得方法

  1. Google Cloud Console にアクセスします。
  2. プロジェクトを作成または選択します。
  3. 「OAuth 同意画面」を設定し、スコープに .../auth/drive.file を追加します。
  4. 「認証情報」から「OAuth 2.0 クライアントID」を作成します（アプリケーションの種類：ウェブ アプリケーション）。
  5. 「承認された JavaScript 生成元」に、このアプリのURL（例：https://localhost:8000 または https://[ローカルIP]:8000）を追加します。

Google Drive に接続

写真を直接Google Driveにアップロードするために、Googleアカウントでサインインしてアクセスを許可してください。
